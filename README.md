## 🐾 What we make

**POS GO** is a point-of-sale app for Thai shops: cafés, stalls, mini-marts, and the people
who run them. It works on iOS and Android, on phones and tablets.

| | |
| --- | --- |
| 🧾 **Sell** | A till built for one hand. Bills, held bills, options, discounts, and promotions. |
| 💳 **Get paid** | Cash, PromptPay QR, gift cards, and split payments, with receipts that print over Bluetooth or the network. |
| 📦 **Stock** | Stock counts, purchase orders, suppliers, lots and expiry dates, and barcode labels. |
| 🙋 **Members** | Loyalty points, member promotions, and campaigns that bring regulars back. |
| 📊 **Reports** | Shifts, takings, margins, and best sellers by branch, plus e-Tax invoices. |
| 🌏 **For everyone** | Thai and English, with light, sunlight, and dark themes. |

## 🧪 How we build

- **Online-only by design.** The server owns prices, stock, permissions, and document numbers.
  A faster wrong total is worse than a slow right one.
- **Measured, not guessed.** Every change passes type checks, lint, and the full test suite
  before it merges. The suites are gated on coverage and run in a random order.
- **Security first.** Secret scanning, dependency audits, and code analysis run in CI.
  A merchant's data is never a debugging aid.
- **Built with** React Native and TypeScript on the device, and .NET on the server.

## 🐄 Why a cat?

Our mascot is a cow-patterned cat, cream with orange and charcoal spots, and its paw is on
everything we ship. In Thai a cow-patterned cat is called *แมววัว*.
